ПЛОСКИЙ КОМПЛЕКТ ДЛЯ ЗАГРУЗКИ В GITHUB С ТЕЛЕФОНА

Все файлы этого архива после распаковки лежат в ОДНОЙ папке, без вложенных папок. Это сделано, чтобы их было проще выделить в файловом менеджере Android и загрузить в корень GitHub-репозитория.

Загружайте все файлы из этой папки в корень репозитория. Не загружайте только ZIP. Не переименовывайте файлы с двойным подчёркиванием: например, site__index.html и netlify__functions__api.js.

В корне обязательно должны оказаться package.json, netlify.toml, prepare-project.js и все файлы с префиксами site__, netlify__, apps_script__, scripts__, docs__.

При сборке Netlify команда из package.json сначала автоматически восстановит исходные папки site, netlify/functions, apps_script, docs и scripts, затем запустит проверку. Поэтому вручную создавать папки в GitHub не требуется.

Секреты в архив не входят. KUPI_API_SECRET нельзя публиковать в GitHub: задайте его отдельно в Netlify и в Script Properties Google Apps Script.

Плоский архив проверен локальной сборкой npm run build. Это проверяет комплектность и синтаксис, но не заменяет живую проверку Google Apps Script и Netlify.
