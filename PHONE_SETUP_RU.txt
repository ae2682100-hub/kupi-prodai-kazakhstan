КУПИ-ПРОДАЙ — КАЗАХСТАН v2.5.3
ИНСТРУКЦИЯ ДЛЯ ТЕЛЕФОНА ANDROID

ВАЖНО: этот архив подготовлен для развёртывания через Git-подключение Netlify. Обычная ручная публикация только HTML-файлов не собирает серверные функции. В этом проекте API и загрузка фотографий зависят от Netlify Functions.

ЧТО УЖЕ ПОДГОТОВЛЕНО
- Корень архива является корнем проекта: netlify.toml, package.json, site/ и netlify/functions/ лежат рядом.
- Netlify build запускает проверку проекта и автоматически упаковывает Functions.
- URL существующего Google Apps Script уже задан как безопасное значение по умолчанию. Если адрес Web App изменится, задайте GAS_WEB_APP_URL в Netlify.
- SITE_BASE_URL больше не обязателен: адрес сайта определяется автоматически для ссылок доступа.
- KUPI_API_SECRET не включён в архив и не показывается сайту. Его нужно задать в Netlify Environment variables.
- Apps Script не перезаписывает сохранённый ключ. Если ключ уже есть в Script Properties, он сохраняется.
- Недельный триггер создаётся только если его ещё нет; существующий триггер не удаляется и не заменяется.

ПУБЛИКАЦИЯ NETLIFY
1. Создайте Git-репозиторий и поместите в его корень содержимое этого архива (не сам ZIP как один файл).
2. В Netlify выберите Add new project / Import from Git и подключите этот репозиторий.
3. Netlify прочитает netlify.toml. Build command: npm run build; Publish directory: site; Functions directory: netlify/functions. Эти значения уже записаны в netlify.toml.
4. В настройках сайта Netlify → Environment variables добавьте KUPI_API_SECRET со своим сохранённым ключом. Не отправляйте ключ в чат и не помещайте его в HTML или Git.
5. Если используется другой адрес Apps Script, добавьте GAS_WEB_APP_URL. Для указанного в проекте существующего адреса эта переменная не требуется.
6. Сохраните переменные и выполните новое развёртывание из Git. После этого будущие обновления репозитория будут собираться автоматически.

ПРОВЕРКА СВЯЗИ
Откройте: https://ВАШ-САЙТ.netlify.app/api?action=health
Ожидаемый результат: ok=true, netlify.function=api, secret_configured=true, google_apps_script.ok=true. Значения ключа ответ не показывает.
Если secret_configured=false — добавьте KUPI_API_SECRET в Netlify. Если Google Apps Script не отвечает — проверьте Web App deployment и URL.

GOOGLE APPS SCRIPT И ТАБЛИЦА
- Не запускайте setupProject повторно без необходимости: он проверяет исходные листы, проверяет/создаёт служебные листы, папку фотографий и недельный триггер. Исходные объявления не очищаются.
- Перед запуском setupProject код сначала проверяет наличие KUPI_API_SECRET в Script Properties. Если его нет, остановится до изменений. Введите ранее сохранённый ключ в Apps Script → Project Settings → Script Properties под именем KUPI_API_SECRET.
- Если ключ уже существует в используемом Apps Script проекте, ничего не меняйте.
- После установки/обновления кода Web App должен быть развёрнут с доступом Anyone и выполнением от имени владельца. При изменении кода обновите существующее развёртывание до новой версии.
- authorizeEmailService запускается один раз вручную из редактора Apps Script, чтобы выдать разрешение на отправку писем.

РАСПИСАНИЕ
Недельный триггер: понедельник, около 06:00, часовой пояс Asia/Almaty. Google запускает временные триггеры приблизительно в выбранный час, не гарантируя секунду.

ОГРАНИЧЕНИЯ
- Ключ Netlify всё равно необходимо один раз внести в защищённые переменные сайта; безопасно встроить его в ZIP нельзя.
- Разрешения Google (таблица, Drive, почта) выдаются владельцем один раз.
- Kaspi-платёж сверяется редактором вручную; автоматического API Kaspi в проекте нет.
- Фото: максимум 5 файлов JPG/PNG/WebP, до 3 МБ каждый на форме.
