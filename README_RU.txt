КУПИ-ПРОДАЙ — КАЗАХСТАН | СБОРКА v2.5.3

Это исправленная сборка проекта v2.5. Содержимое архива является корнем Git-репозитория.

ОСНОВНЫЕ ЧАСТИ
- site/ — шесть HTML-страниц сайта.
- netlify/functions/ — защищённый API-шлюз и endpoint выпуска.
- apps_script/ — Google Apps Script для таблицы, Drive, объявлений, выпусков, платежных запросов и редакторской панели.
- netlify.toml — конфигурация сборки, Functions и маршрутов.
- scripts/build-check.js — проверка проекта перед публикацией.
- PHONE_SETUP_RU.txt — пошаговая инструкция для Android.

ИСПРАВЛЕНИЯ
1. Исправлена структура архива: файлы проекта лежат в корне репозитория, а не во вложенной папке.
2. Добавлена команда npm run build, проверяющая файлы и синтаксис перед публикацией.
3. Netlify настроен на сборку и упаковку Functions через esbuild.
4. URL ранее используемого Google Apps Script задан как fallback; GAS_WEB_APP_URL нужен только при другом URL.
5. KUPI_API_SECRET не хранится в архиве. Netlify получает его из Environment variables.
6. Apps Script больше не содержит встроенный ключ и не перезаписывает сохранённое Script Property.
7. Setup сначала проверяет ключ, прежде чем изменять таблицу или Drive.
8. Существующий недельный триггер не удаляется и не пересоздаётся.
9. Добавлена безопасная проверка /api?action=health без раскрытия секрета.
10. SITE_BASE_URL не обязателен — ссылки доступа формируются с адресом текущего сайта.

ФУНКЦИИ ПРОЕКТА
Подача объявлений; загрузка до пяти фотографий; ручная модерация; редакторский вход с одноразовым кодом по email; бесплатный выпуск; платный доступ после ручной проверки оплаты; последовательная нумерация выпусков; автоматический выпуск по понедельникам около 06:00 Asia/Almaty.

ВАЖНО
Обычная ручная публикация статических HTML-файлов не гарантирует сборку и публикацию Netlify Functions. Используйте Git-подключение Netlify, как описано в PHONE_SETUP_RU.txt. Не публикуйте KUPI_API_SECRET в репозитории, HTML или сообщениях.


ПОЛНЫЙ АРХИВ v2.5.3
Перед загрузкой в GitHub распакуйте ZIP и перенесите в корень репозитория всё его содержимое вместе с папками. Контрольный список находится в DEPLOY_NETLIFY_RU.txt. Сборка дополнительно проверяет наличие всех 21 обязательного файла.

ВАЖНО ДЛЯ ПРОВЕРКИ НА ТЕЛЕФОНЕ: сначала полностью распакуйте ZIP в отдельную папку. Не открывайте index.html из режима просмотра архива: ZIP-просмотрщик часто не умеет переходить между соседними HTML-файлами. После распаковки откройте index.html из распакованной папки; файлы ad-form.html и free-issue.html должны находиться рядом в папке site.
