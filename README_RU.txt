ЧТО СВЯЗАНО В КОДЕ
1. Подача объявления со статусом pending в существующий лист «Объявления».
2. Справочники читаются из 4 листов Google Таблицы.
3. До 5 фотографий JPG/PNG/WebP загружаются по одной в Google Drive. Для стабильности Netlify ограничение установлено 3 МБ на фото (не 5 МБ, как в старой форме).
4. Редакторский вход: только veelts139@gmail.com, одноразовый код на почту, 10 минут, ограничение попыток, сессия 6 часов.
5. Модерация: approve / reject / review.
6. Покупка выпуска: запрос на 500 ₸; Kaspi проверяется человеком вручную; после подтверждения создаётся персональная ссылка до следующего понедельника 06:00.
7. Выпуски: порядковый номер 0000001 и далее; новые одобренные объявления добавляются только один раз; триггер по понедельникам около 06:00 Asia/Almaty.
8. Рекламный шифр — отдельно от номера выпуска: [1–3][YY][MM][DD], показывается не в каждом выпуске и помечается как условный, не как фактическая статистика.
9. Бесплатный выпуск скрывает контакты. Полный показывает контакты только при согласии автора и валидном персональном токене.
10. Публичный архив закрыт; старые выпуски доступны только по действующей персональной ссылке.
11. Отзывы сохраняются в лист «Отзывы».
12. Кнопки PDF оставлены неактивными.

ВАЖНО О ПЛАТЕЖАХ
Автоматического API Kaspi в этой сборке нет. Сайт записывает запрос покупки. Редактор сверяет поступление 500 ₸ в Kaspi самостоятельно и только потом нажимает «Подтвердить оплату и выдать доступ». Не отправляйте ссылку до фактической проверки платежа.

УСТАНОВКА GOOGLE APPS SCRIPT
1. В новом Apps Script проекте создайте/переименуйте файлы Code.gs, Database.gs, Ads.gs, IssuesPayments.gs, Admin.gs.
2. В каждый файл вставьте одноимённый .gs из папки apps_script. Код распределён по файлам, функции используют общие глобальные настройки из Code.gs. Не добавляйте старые версии кода.
3. Включите показ файла манифеста appsscript.json (Project Settings / Show appsscript.json) и замените его содержимое манифестом из архива.
4. Сохраните проект.
5. В выпадающем списке функций выберите setupProject и нажмите Run. Разрешите доступ к таблице и Google Drive. Эта функция проверяет исходные 7 листов и заголовки, НЕ очищает и НЕ перезаписывает их; создаёт только служебные листы «Выпуски», «Платежи», «Отзывы», «Разрешения», папку Drive для фотографий и еженедельный триггер.
6. Запустите authorizeEmailService один раз и разрешите отправку почты. Это нужно для одноразового кода редактора.
7. Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone. Разверните и скопируйте URL вида https://script.google.com/macros/s/.../exec.
8. Не передавайте этот URL с секретом третьим лицам. Сам URL не является секретом, но API закрыт общим ключом, который хранится на сервере Netlify.

УСТАНОВКА NETLIFY
В корне папки проекта находятся site/, netlify/functions/ и netlify.toml. Публиковать нужно весь проект как Netlify-проект с включёнными Functions (удобнее через подключение Git-репозитория; простая загрузка только папки site не загрузит функции).
В Netlify → Site configuration → Environment variables добавьте:
GAS_WEB_APP_URL = URL Web App из шага 7
KUPI_API_SECRET = значение INTERNAL_API_SECRET из Code.gs (не публиковать)
SITE_BASE_URL = полный адрес вашего сайта Netlify, например https://имя-сайта.netlify.app
После добавления переменных запустите новый deploy.

ПРОВЕРКА
1. Откройте адрес сайта Netlify — главная страница должна открыться.
2. Отправьте тестовое объявление с одной небольшой фотографией. Проверьте строку в «Объявления», статус pending и файл в папке Drive.
3. Откройте /admin.html, запросите одноразовый код на veelts139@gmail.com, войдите, одобрите тестовое объявление.
4. В редакторской панели нажмите «Создать выпуск сейчас» для теста. Проверьте лист «Выпуски» и заполнение issue_id в одобренном объявлении.
5. Откройте бесплатный выпуск — контакты не должны отображаться.
6. Создайте запрос на покупку. После реальной проверки тестового платежа в Kaspi редактор выдаёт доступ. Не подтверждайте фиктивную оплату.
7. Удалять тестовые строки вручную можно только после проверки, если вы уверены, что это именно тестовые данные.

ОГРАНИЧЕНИЯ / ЧТО НЕ ПОДМЕНЯЕТСЯ
- Автоматическая проверка объявлений искусственным интеллектом не включена: новые заявки попадают редактору на ручную проверку. Автоматическое одобрение не применяется.
- Автоматическая сверка Kaspi не включена: требуется ручная проверка.
- Google Apps Script и Netlify имеют квоты/лимиты; большие фото и массовый трафик потребуют отдельной оптимизации.
- В справочнике городов нет поля связи с регионом; города загружаются как общий справочник. Выбор региона и города работает, но строгая фильтрация городов по региону требует изменения структуры таблицы, поэтому в этой версии исходные 7 листов не изменяются.
- Доступность почтового кода зависит от разрешений Google Apps Script и лимитов MailApp.
- Не публикуйте API secret в HTML, открытом репозитории или сообщениях.

СОХРАНЕНИЕ ДАННЫХ
Исходные семь листов и все исходные объявления не очищаются. setupProject только проверяет заголовки и добавляет три служебных листа. Перед первой установкой рекомендуется сделать копию Google Таблицы через меню Google Sheets.


ВАЖНО ДЛЯ ПРОДОЛЖЕНИЯ УЖЕ НАСТРОЕННОГО ПРОЕКТА
Если Google Apps Script уже развёрнут и отвечает health=ok, не создавайте новый проект Apps Script,
не запускайте повторно setupProject без необходимости и не меняйте Google Таблицу.
Для нового отдельного сайта Netlify используйте тот же действующий GAS_WEB_APP_URL и тот же
KUPI_API_SECRET, которые соответствуют Script Properties текущего Apps Script.
Секрет не отправляйте в чат и не размещайте в публичном репозитории.
Для Netlify необходимо развернуть корень проекта, чтобы netlify.toml и netlify/functions
были доступны системе сборки. Публикуемая папка сайта — site.
